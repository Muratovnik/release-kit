# Документация release-kit на русском языке

Канонической остаётся [документация на английском языке](../../README.md). Русские
руководства покрывают путь внедрения гейта: установку, первую проверку, политику аудита
и обновления. Они относятся к тому же релизу, что и английские документы.

| Задача | Документ |
| --- | --- |
| Установить CLI и выполнить первую проверку | [Обзор и быстрый старт](../../README.ru.md) |
| Настроить приватные пути, базовые линии, правила владельца, защиту или overlay | [Политика и области аудита](audit.md) |
| Обновить закреплённый CLI проекта, обновить защиту, откатиться или восстановиться | [Обновления и восстановление](updates.md) |

## Документы только на английском языке

Эти поверхности адресованы интеграторам и сопровождающим, а не установке и повседневному
использованию гейта:

| Задача | Документ |
| --- | --- |
| Проверить и выгрузить курируемые заметки к релизу | [Release notes](../notes.md) |
| Собрать локально и доставить в каталог или на GitHub | [Local releases](../local-releases.md) |
| Поддерживать публикацию через GitHub Actions | [Actions adapter](../release-coordinator.md) |
| Использовать плагин для агентов | [Plugin](../plugin.md) |
| Интегрировать другой локальный MCP-клиент | [Standalone MCP](../mcp.md) |
| Потреблять машиночитаемые результаты | [CLI JSON contract](../cli-json.md) |
| Разобраться в закреплении платформ, кэшах и границах доверия | [Distribution](../distribution.md) |
| Проверить поверхности, которые локальный аудит не видит | [Publication review](../publication-review.md) |
| Собрать проект из исходного кода | [CONTRIBUTING.md](../../CONTRIBUTING.md) |
| Узнать, что изменилось между версиями | [CHANGELOG.md](../../CHANGELOG.md) |
| Сообщить об уязвимости | [SECURITY.md](../../SECURITY.md) |
| Проверить лицензию | [LICENSE](../../LICENSE) |

Вывод команд, имена правил, ключи конфигурации и сообщения CLI не переводятся: перевод
сообщения сделал бы его непригодным для поиска по документации и по исходному коду.
